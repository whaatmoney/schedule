# Viva Engage templates

A single page techs keep open to copy the post format for their department.

| File | What it is | Who edits it |
|---|---|---|
| `index.html` | The page. Rules, per-department templates, photo standards, sources. | Authored. Tyler approves format changes. |

## Ground rules

- Formats come from QPC's posting guidelines, production directives, and real posts in the Viva Engage export. Each department block names its source and how confident that source is.
- No people are named in formats or rules. This is etiquette, not a performance review.
- Change a format only when the guideline or a directive changes. Note the source in the same edit.
- The aging pipeline never writes to this folder.
